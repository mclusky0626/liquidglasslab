Liquid Glass

빛을 휘게 하는
웹 위의 유리.

리퀴드 글래스는 가장자리에서 빛을 꺾고, 테두리에 빛을 맺히게 하고, 손끝을 따라 늘어납니다. 이 페이지의 유리는 전부 HTML, CSS, SVG로 만들었습니다.

유리를 끌어서 글자 위로 옮겨 보세요

일단 핵심부터.

  • LIQUID

    굴절. 유리 가장자리를 지나는 배경이 안쪽으로 휘어 들어옵니다. 평평한 블러에는 없는 두께가 생깁니다.

  • 반사광. 테두리를 따라 빛이 맺히고, 빛이 움직이면 하이라이트도 따라 돕니다.

  • 유동성. 움직일 때 늘어나고, 멈출 때 살짝 튕기며 제자리를 찾습니다.

  • 밝은 사진 위에서는 유리가 어두운 글자를 씁니다. 배경의 밝기를 읽어 색조와 글자색을 바꿉니다.

스넬의 법칙.

n₁ sin θ₁ = n₂ sin θ₂

빛은 밀도가 다른 물질로 들어갈 때 꺾입니다. 곡면이 가파를수록 많이 꺾이므로, 평평한 가운데는 그대로 보이고 둥근 가장자리에서만 배경이 휘어 보입니다. 변위 맵이 가장자리에서만 진한 이유입니다.

프레넬 효과.

R(θ) = R₀ + (1 − R₀)(1 − cos θ)⁵

빛이 표면에 비스듬히 닿을수록 더 많이 반사됩니다. 정면에서 4% 남짓인 유리의 반사율이 스치듯 닿으면 100%에 가까워집니다. 테두리가 가운데보다 밝게 빛나는 이유입니다.

    접근성

    읽을 수 있어야
    아름답습니다.

    투명한 UI는 누군가에게는 읽기 어려운 UI입니다. 운영체제의 손쉬운 사용 설정을 CSS 미디어 쿼리로 존중하세요. 아래 스위치는 이 페이지 전체에 바로 적용됩니다.

    • 투명도 줄이기

      유리를 불투명한 면으로 바꿉니다. 뒤가 비치지 않으니 글자 대비가 일정해집니다.

      @media (prefers-reduced-transparency: reduce)

    • 동작 줄이기

      튕기는 스프링과 자동 재생을 멈춥니다. 어지러움을 느끼는 사람에게 필요합니다.

      @media (prefers-reduced-motion: reduce)

    • 대비 높이기

      색조를 진하게, 테두리를 또렷하게 만듭니다. 화려한 배경 위에서도 경계가 보입니다.

      @media (prefers-contrast: more)
    1. 굴절 효과는 SVG 필터를 backdrop-filter: url()에 연결하는 방식이라 Chrome, Edge 등 Chromium 계열 브라우저에서만 동작합니다. Safari와 Firefox에서는 같은 요소에 blur()와 saturate()로 만든 대체 스타일이 자동으로 쓰입니다.
    2. 프레임 속도는 이 페이지를 연 기기에서 requestAnimationFrame 호출 간격으로 잰 값이며, 기기 성능과 화면 주사율에 따라 달라집니다.
    3. 굴절률은 노란 나트륨 빛(589nm) 기준의 대표값입니다. 물 1.33, 일반 판유리 약 1.52, 다이아몬드 2.42.
    4. 레이어 구성, 스프링 곡선 cubic-bezier(0.34, 1.56, 0.64, 1), 드래그 임계값과 탄성 범위는 velog의 「Apple Liquid Glass UI 패턴」 글을 참고했습니다.
    5. Apple, iPhone, Liquid Glass는 Apple Inc.의 상표입니다. 이 페이지는 Apple과 관련이 없는 학습용 데모이며, Apple 제품 소개 페이지의 구성 방식을 참고해 만들었습니다.
